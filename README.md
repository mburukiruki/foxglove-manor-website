Foxglove Manor Adult Family Home Website

This is the official repository for the Foxglove Manor Adult Family Home website project.
Target Launch Date: January 15, 2026

Project Overview

Foxglove Manor is an Adult Family Home (AFH) located in Mount Vernon, Washington. This website serves as the primary digital marketing and communication platform for the business.

Design Aesthetic

Primary Vibe: Medical yet Homey

Color Palette: Sage Green, White, and Slate Grey

Key Emotions: Trust, Calm, Professionalism, Warmth

Features (Current Prototype)

Responsive Navigation: Mobile-friendly menu.

Hero Section: Welcoming introduction with "Schedule a Tour" CTA.

Services Breakdown:

Specialized Care (Dementia/Alzheimer's)

Clinical Support (Diabetes, Respiratory, etc.)

Daily Living (Meals, Housekeeping)

Contact Form: Integrated inquiry form.

Technology Stack

React.js

Tailwind CSS

Lucide React (Icons)
